# PanPan Auto

English B2B wholesale site for [panpanauto.com](https://panpanauto.com). PanPan Auto is a multi-brand **authorized dealer / distributor** for auto film and selected parts (ISF, NKODA, NANOLINK), operated by PanPanTech. It is not a factory website.

Email, WeChat, address, hours, MOQ, warranty, lead time, and Incoterms are **TBD** until confirmed. The site does not invent those figures.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production build:

```bash
npm run build
npm start
```

Requires Node.js 20 or newer.

## Inquiry form

`POST /api/inquiry/` accepts the contact form. Required fields: company, contact name, role, country or region, work email, at least one product interest, and consent.

Optional environment variable (see `.env.example`):

```bash
INQUIRY_WEBHOOK_URL=https://example.com/hooks/inquiry
```

When `INQUIRY_WEBHOOK_URL` is an `http` or `https` URL, the server forwards the inquiry JSON to it. When it is unset, the server accepts the inquiry and writes it to the process log. Copy `.env.example` to `.env.local` for local development. Do not commit secrets.

`/inquiry/` permanently redirects (301) to `/contact/` and keeps the query string, including `intent` (`sample`, `wholesale`, `dealer`, `starter`, `full-body`).

## Vehicle photos

Hero, pillar, series, and proof images are **Xiaomi EV reference photos** taken from public pages on [xiaomiev.com](https://www.xiaomiev.com) (SU7, YU7, and related studio imagery). Every figure is captioned as a Xiaomi EV reference, **not a PanPan installation or case study**. Review brand-use rights before a public launch if your counsel requires a license beyond this reference treatment.
